# AI Summit Seoul 2026 — Session Report

A plain-language, session-by-session record of AI Summit Seoul (AIS26), reconstructed from on-site photos and live-translation captures across August 19–20, 2026.

**[Read the report → `index.html`](./index.html)**

## What's inside

- A 5-minute "if you only read one thing" summary
- A short glossary of the recurring jargon (Agentic AI, AX, Harness Engineering, Sim-to-Real gap, World model, FDE)
- Session-by-session write-ups for all 21 talks and panels across both days, each with a one-line plain-English summary, key points, and a takeaway
- Expo floor highlights
- Four cross-cutting themes that came up across the whole summit

## Sourcing caveats

This was built from a phone's live-translation screenshots (Flitto's real-time English captioning) and photos of presentation screens — not an official transcript. Figures and quotes are the speakers' own claims relayed through machine translation; a few names have uncertain spelling; some sentences are cut off where a UI element covered the caption feed. See the "How this report was built" section inside `index.html` for full detail before citing anything externally.
